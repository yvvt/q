## в корне

- `config.py` — системный промпт, формат ответа (регулярные выражения), допуск ±1%, словарь моделей и тарифы.
- `prompts.py` — сборка пользовательских промптов по типам задач (A–F), включая few-shot промпт типа E.
- `clients.py` — единая функция `ask()`: OAuth GigaChat, OpenAI-совместимые API Yandex и Ollama; логирование каждого вызова в JSONL.
- `bank.py` — загрузка и валидация банка задач (обязательные поля, уникальность id).
- `run_bank.py` — прогон банка (типы A–D, F) по всем моделям с температурой 0, с пропуском уже выполненных задач.
- `run_type_e.py` — прогон типа E (0/5/20 примеров в промпте, 100 тестовых строк) по всем моделям.
- `type_e_data.py` — подготовка AI4I 2020: разбиение на тест и few-shot пулы, текстовое представление строк, базлайны LR/NB.
- `evaluate.py` — парсинг ответов, автопроверки A/B/F, присоединение ручной оценки C/D/F, сводные таблицы, сохранение предсказаний базлайнов.
- `prepare_blind_review.py` — формирование слепой таблицы для рецензентов (без имён моделей) и закрытого ключа соответствия.
- `evaluate_manual.py` — чтение оценок двух рецензентов, каппа Коэна, список расхождений, консенсус.
- `analysis.py` — ДИ бутстрепом, МакНемар (exact), отказы, таблицы гипотез H3/H5/H12, ECE и диаграммы надёжности, стоимость/скорость, кандидаты ошибок, все графики.
- `lr3_localqwen.ipynb` — прогон локальной Qwen в Colab.
- `qw` — предрегистрация гипотез и прогноза (коммит 29.10, до прогонов).
- `combined_ca.pem` — цепочка сертификатов для TLS-подключения к GigaChat API.
- `.gitignore` — исключения git.

## data/

- `tasks.jsonl` — банк из 40 задач (id, тип, тема, тексты ru/en, эталон, допуск, источник, сложность).
- `test_tasks.jsonl` — 5 отладочных задач, на которых отлаживался промпт; в оценку не входят.
- `ai4i2020.csv` — датасет AI4I 2020 Predictive Maintenance для типа E.
- `tasks.jsonl.txt` — текстовая копия банка (дубликат, в коде не используется).

## logs/

- `<model>.jsonl` — сырые логи всех вызовов: промпт, ответ, токены, время, метаданные; первоисточник всех результатов.

## review/

- `blind_review.xlsx` — пустая слепая таблица, отправленная рецензентам.
- `blind_review_ans1.xlsx`, `blind_review_ans2v2.xlsx` — две независимые слепые оценки рецензентов.
- `blind_mapping.json` — ключ response_id → модель; вскрыт после сдачи обеих оценок (коммит одновременно с ответами рецензентов).

## results/

- `eval_bank.csv` — построчная проверка банка: распарсенный ответ, верность, уверенность, токены, время, поля ручной оценки.
- `eval_type_e.csv` — построчные результаты типа E (предсказание, истинный класс, n_shots).
- `summary_bank.csv`, `summary_type_e.csv` — сводки «модель × тип» и «модель × n_shots» (точность, отказы, pass@1, доля методологических ошибок, константный базлайн).
- `classical_preds.csv` — построчные предсказания LR и NB на тех же 5/20 примерах и том же тесте (сравнение для H12).
- `type_e_split.json` — зафиксированное разбиение AI4I (тест, few5, few20); создано до прогонов.
- `manual_long.csv`, `manual_summary_per_reviewer.csv` — оценки каждого рецензента и его метрики.
- `manual_agreement.csv` — согласие рецензентов: raw agreement и каппа Коэна по полям рубрик.
- `manual_disagreements.csv` — расхождения рецензентов для обсуждения после разслепления.
- `manual_consensus_long.csv`, `manual_consensus_summary.csv` — консенсус двух рецензентов (итог для метрик).
- `manual_for_heatmap.csv` — значения C/D/F для тепловой карты.
- `results(eval.py_console).txt.txt` — консольный вывод `evaluate.py`.
- `analysis/` — таблицы `analysis.py`: `accuracy_ci.csv` (точность с ДИ), `mcnemar_all_types.csv`, `refusal_rates.csv`, `h3_unresolvable.csv`, `h12_fewshot.csv`, `cost_speed.csv`, `ece_reliability.csv`, `error_candidates.csv` (кандидаты для разбора пяти ошибок).
